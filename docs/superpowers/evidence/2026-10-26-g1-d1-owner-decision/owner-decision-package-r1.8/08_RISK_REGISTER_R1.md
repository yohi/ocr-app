# 08. 必須リスク台帳（Risk Register R1）

## 1. 概要と分類基準（FND-ODP-006是正）

本リスク台帳は、G1-D1 未解決19件の再試験および意思決定プロセスに伴う12の重要リスクを抽出し、**確認済み事実（Fact）**、**作業仮説（Hypothesis）**、**未証明事項（Unverified）** を客観的に分離して評価するものです。

R0 に存在した「完全排除」「リスクゼロ」「必ず安全」等の過剰な断定表現を撤廃し、証拠に基づいた客観的判定ステータス（`MITIGATED`, `RESIDUAL_RISK_REMAINS`, `EXECUTION_NOT_VERIFIED`, `PENDING_EVIDENCE`, `STOP_ON_VIOLATION`）に再分類しました。

## 3. 残存リスクへの総括技術助言

1. **最大の不確実性**:
   - ホスト側の npm キャッシュ内に真に必要な tarball が揃っているか（DEC-01A による調査が最優先）。
   - TEST-14 における Node.js 20.20.2 のタイマー挙動と外側60秒タイムアウトの実機干渉（Stage 4 の単独実行トレースが不可欠）。
2. **推奨される防護姿勢**:
   - 早期に一括承認を行わず、**方式A（Stage別承認）** に従い、Stage 0（受入）、Stage 1（依存）、Stage 2〜4（各グループ）の一次証跡を1つずつ確認して進めること。
